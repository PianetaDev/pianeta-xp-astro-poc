Contenuti bocciati da Max prima della pubblicazione, tenuti qui **non come materiale da recuperare** ma come esempio di cosa non fare — per chi scrive (MUSE) e per chi rivede.

Ogni file ha una nota in testa con: perché è stato bocciato, la issue Paperclip collegata, la PR (se esisteva). Il testo sotto la nota è la versione originale bocciata, non modificata.
